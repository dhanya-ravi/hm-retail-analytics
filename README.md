
# H&M Retail Analytics

Retail transaction analysis using MySQL and Power BI.

## Project overview
This project explores the H&M transaction dataset (Sep 2018–Sep 2020), containing approximately 31.8 million transaction records.

## Tools
- MySQL
- Power BI

## Current work
- Analyzed monthly transaction-line volume and active-customer activity in MySQL.
- Created a Power BI report visualizing monthly trends.

## Planned extensions
- Product-category and sales-channel analysis
- Customer cohort and repeat-purchase analysis
- Additional findings and dashboard improvements

## Repository contents
Project SQL queries, aggregated analysis outputs, and Power BI report screenshots will be added here as the project develops.
